# InvestCase

Uma plataforma criada para aproximar **startups e investidores** de uma forma mais simples, organizada e conectada.

O **InvestCase** nasceu da ideia de criar um ambiente onde startups possam apresentar seus negócios e investidores possam descobrir novos projetos e oportunidades de investimento.

O projeto ainda está em desenvolvimento e continuará evoluindo conforme novas funcionalidades forem construídas.

## 💡 Sobre o projeto

O **InvestCase** funciona como uma rede voltada ao ecossistema de startups e investimentos.

Startups poderão apresentar seus negócios, enquanto investidores poderão explorar empresas e oportunidades de acordo com seus interesses. A plataforma também pretende reunir informações relevantes para esse ecossistema, como eventos e oportunidades de financiamento.

Nosso objetivo é facilitar esse processo de descoberta e conexão, reunindo em um único ambiente informações que normalmente estão espalhadas em diferentes lugares.

## 🚧 Status

> **Em desenvolvimento**

Atualmente estamos construindo a estrutura inicial da aplicação, incluindo a API, os principais modelos do sistema e a documentação dos endpoints.

O projeto está sendo desenvolvido de forma incremental, permitindo que novas funcionalidades sejam implementadas e aprimoradas ao longo do tempo.

## 🛠️ Tecnologias

O back-end está sendo desenvolvido utilizando:

- **C#**
- **ASP.NET Core**
- **PostgreSQL**
- **Entity Framework Core**
- **Swagger / OpenAPI**
- **Git & GitHub**

Outras tecnologias poderão ser incorporadas conforme as necessidades do projeto.

## 📚 API

O **InvestCase** possui uma API REST responsável pela comunicação entre o front-end e os recursos da plataforma.

Durante o desenvolvimento, os endpoints podem ser visualizados e testados através do **Swagger**, que também disponibiliza a especificação OpenAPI da API.

> Algumas funcionalidades e respostas da API ainda são provisórias enquanto a integração com o banco de dados está em desenvolvimento.

## 🎯 Objetivo

Mais do que simplesmente listar startups ou investidores, queremos construir um ambiente que facilite a descoberta de oportunidades e ajude a criar conexões relevantes dentro do ecossistema.

O **InvestCase** está apenas começando. 🚀
